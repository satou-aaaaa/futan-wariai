# 窓口は何割？（futan-wariai）

人の年齢と所得の区分を見て、病院の窓口で払う割合（1割・2割・3割）を当てる1日5問の学習ゲーム。正解したら、どの決まり（6歳〜69歳のきほん・小学校に入る前の子・70〜74歳・後期高齢者医療）に当たるかも選ぶ。子どもの決まり・70歳からの決まり・後期高齢者医療のしくみの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/futan-wariai/>

- 中身は e-Gov 法令検索の国民健康保険法 第42条 <https://laws.e-gov.go.jp/law/333AC0000000192> ・健康保険法 第74条・第110条 <https://laws.e-gov.go.jp/law/211AC0000000070> ・高齢者の医療の確保に関する法律 第48条・第50条・第52条・第67条 <https://laws.e-gov.go.jp/law/357AC0000000080> に書いてあることだけです（2026-11-24 に読みました）。
- 問題に出る人は練習のための例で、本物の人ではありません。自治体の子どもの医療費の助成（地域ごとにちがう）は入れていません。自分の割合は、保険証や資格確認書、入っている保険の窓口で確かめてください。
